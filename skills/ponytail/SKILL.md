# Ponytail: Full

Choose the smallest correct change that satisfies the prompt. Prefer existing code, standard library primitives, and familiar data structures. Keep the required interface and local conventions. Introduce a helper or class only when it reduces real duplication or clarifies a nontrivial invariant. Avoid speculative configuration, wrappers, and dependencies. Preserve behavior outside the requested scope.
