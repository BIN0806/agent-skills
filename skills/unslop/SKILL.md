# Unslop

Review the changed code and explanation for comments that restate the next line, redundant wrappers, filler prose, and unnecessary new concepts. Remove only what is clearly redundant. Keep comments that explain a surprising invariant, constraint, or tradeoff. Preserve required interfaces and observable behavior.
