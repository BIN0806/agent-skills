# How

Trace the entry point through callers, key data transformations, and state mutations. Identify the file or function that owns the behavior and the nearest tests. Explain the flow in a few concrete steps with file references. Distinguish observed behavior from inference. Stop exploring once the path relevant to the requested change is clear.
