# Research a topic

- Define the question and the decision the answer supports. Search the relevant project or local resources first when they contain the facts, then use authoritative external sources for facts the project cannot establish.
- Follow material claims to the source that owns them. Check versions, publication dates and the environment to which the evidence applies. For a disputed point, compare the relevant source and actual behavior where feasible.
- Separate observed facts, source claims, inference and open questions. Cite each consequential claim near the text it supports, with enough detail to revisit the evidence.
- Match the deliverable to the request. A direct question can receive a cited answer. For a reusable note, use the project's existing location, record the scope and date, and link supporting material instead of duplicating it.

Additional researchers can divide independent questions when delegation is authorized and available. Otherwise investigate directly. End with what the evidence establishes and how any unresolved question affects the user's decision.
