# Verification Before Completion

Run the smallest relevant local test command and check the result. Exercise edge cases that distinguish the chosen approach from common mistakes when practical. Report the command, outcome, and any untested limitation accurately. If no runnable tests exist, say what was inspected or reasoned through instead of claiming a test pass.
