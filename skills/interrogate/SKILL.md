# Interrogate

Identify the few unknowns that could change correctness or complexity: input size, allowed mutation, duplicate handling, invalid input behavior, ordering, and required interface. Check the prompt and existing tests before asking. State a reasonable assumption when work can continue safely; ask a focused question only when the answer changes the implementation. Include adversarial cases relevant to the actual problem, rather than a generic checklist.
