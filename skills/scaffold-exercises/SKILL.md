# Scaffold exercises

- Read the requested learning plan, adjacent exercises, numbering conventions and available course checks. Choose the exercise variants the objective actually needs, such as a problem workspace, solution or conceptual explanation.
- Give each exercise a concrete objective, prerequisites, instructions and a way to recognize success. A starter should contain meaningful content and relevant entry points. Keep solutions distinguishable from the learner's workspace.
- Follow the existing directory and filename conventions. If the course has none, use an ordered layout that makes sections and exercise variants easy to locate. Preserve existing learner work during updates and reset only when requested.
- Check links and any supplied code with the project's actual tools. Use AI Hero's internal linter only in a project where it is installed and documented. Update references when renaming an exercise, and run the relevant course checks after the move.

Report the new exercise paths, how the learner starts, how they check their work, and which validation was run.
