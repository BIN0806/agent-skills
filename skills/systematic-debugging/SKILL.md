# Systematic Debugging

Reproduce the failure with the smallest useful input. Compare actual and expected behavior, then state the assumption the result disproves in one or two sentences. Trace the failing path and apply a targeted correction. Rerun the reproduction and relevant tests. For a timeout, measure or reason about the hot path and input bounds before changing the algorithm.
